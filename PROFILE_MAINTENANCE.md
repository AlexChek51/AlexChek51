# Обновление профиля

- `README.md` — основная русская версия; `README.en.md` — английская.
- `PROJECTS.md` — подробные описания проектов.
- `scripts/build-profile.mjs` — генератор SVG-обложки и статистики, без npm-зависимостей.
- `assets/` — готовые картинки в светлой и тёмной темах. GitHub выбирает тему через `<picture>`.

## Источники статистики

Генератор получает только публичные данные AlexChek51:

- профиль и список публичных репозиториев через GitHub REST API;
- объёмы языков через `/repos/{owner}/{repo}/languages`, исключая forks и репозиторий профиля;
- вклад за последние 12 месяцев из публичной страницы календаря GitHub.

Jupyter Notebook учитывается как формат файлов, который показывает GitHub. Его объём включает JSON и сохранённые результаты; он не равен количеству написанного Python-кода. Диаграмма языков не является оценкой уровня владения технологиями. Текущий коммерческий стек описан отдельно в README.

Числа не моделируются и не дополняются выдуманными коммитами. Если API или парсер календаря не отработает, генератор завершится с ошибкой до записи файлов. Последние успешно созданные SVG останутся в репозитории.

## Автообновление

GitHub Actions запускается по понедельникам, при изменении генератора/workflow и вручную через **Actions → Update profile statistics → Run workflow**. Используется встроенный `GITHUB_TOKEN`; личный токен или сторонний сервис статистики не нужен. Зависимости GitHub Actions закреплены на конкретные SHA.

GitHub может приостановить scheduled workflow публичного репозитория после длительного отсутствия активности. В таком случае включите workflow на вкладке Actions и запустите его вручную.

Локальный запуск на Node.js 24:

```bash
node scripts/build-profile.mjs
```

Без `GITHUB_TOKEN` действуют лимиты публичного API. При необходимости передайте токен через окружение, не сохраняя его в репозитории.

После публикации сайта-портфолио добавьте адрес в README обеих языковых версий и в поле Website профиля.
