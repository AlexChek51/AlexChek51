## ООО «Прогрессима»

### LANDAX.AI — SaaS для рекламных лендингов

**Задача.** Дать команде инструмент для локализации и переработки рекламных лендингов, обработки файлов и доставки результата. Объединить AI-операции, пользователей, биллинг и рекламную аналитику в одном сервисе.

**Мой вклад.** Разрабатывал backend на FastAPI/PostgreSQL и интерфейс на Jinja2, Vanilla JavaScript и Bootstrap. Реализовал обработку ZIP-архивов с проверкой содержимого и антивирусным сканированием, работу с HTML с сохранением структуры страницы, стилей и JavaScript, доставку по SSH/SFTP.

Подключил OpenAI, Gemini и ComfyUI/Flux для работы с текстом и изображениями. Реализовал балансировку API-ключей, ограничения частоты запросов, повторные попытки с задержкой, учёт токенов, стоимости и времени выполнения. Длительные операции выполняются через Celery/Redis; предусмотрены статусы, прогресс, контрольные точки и сохранение результатов.

Разработал роли и права доступа, биллинг, учёт операций и затрат по пользователям, публичный REST API и локализацию интерфейса на шесть языков. Через Airflow организовал ETL-процессы для рекламной статистики Binom с сохранением в PostgreSQL. Настраивал развёртывание и сопровождение сервиса на Linux, Docker и Nginx.

**Сложность.** Согласовать работу файлового конвейера, платных AI-провайдеров, фоновых задач и финансового учёта. При сбоях важно сохранить состояние операции и корректно показать пользователю её результат и стоимость.

[Сайт LANDAX.AI](https://landax.ai/)

### AvatarAI — платформа производства AI-видео

**Задача.** Собрать процесс создания ролика в одном продукте: проекты, аватары, сценарии, раскадровка, генерация сцен, озвучка, субтитры и финальная сборка.

**Мой вклад.** Разрабатывал backend и интеграции AI-провайдеров. Разделил HTTP-обработчики, прикладную логику, клиентов провайдеров и фоновые worker-процессы; состояния заданий и стадий сохранял в PostgreSQL. Подключил генерацию текста, изображений, видео и озвучки, распознавание речи через Faster Whisper, сборку через FFmpeg/SoX.

Ролик может длиться от 6 до 180 секунд; один запуск включал до 10 видео- и 20 image-операций. Для долгих и платных операций сохранял идентификаторы провайдера, возобновлял проверку уже запущенной генерации и исключал автоматическую повторную отправку при неоднозначном ответе. Добавил ограничения параллельности, восстановление после перезапуска и повторное выполнение отдельных неуспешных стадий.

Настраивал Docker, Nginx и Linux-окружение. Предусмотрел проверки активных генераций и процессов FFmpeg перед обновлением контейнеров. Устранял блокировки event loop тяжёлыми операциями, работал с пулом соединений и запросами PostgreSQL.

**Стек:** Python, FastAPI, PostgreSQL, Jinja2, JavaScript, внешние AI API, Faster Whisper, FFmpeg, SoX, Docker, Nginx, Linux.

### Cliparium, Kairo и Channeloom — Telegram Mini Apps

Разработал три независимо разворачиваемых продукта на FastAPI, aiogram, PostgreSQL, Redis и Vanilla JavaScript. Реализовал HMAC-проверку Telegram initData, изоляцию данных клиентов, идемпотентность, optimistic locking и lease-механику для конкурентных worker-процессов.

Подготовил 18 Alembic-миграций. На Linux DEV-сервере развернул отдельные Docker Compose-проекты с собственными сетями, volumes и API/bot/worker-процессами. Настроил Nginx, Cloudflare Tunnel, health checks, ограничения ресурсов и доступ к PostgreSQL/Redis только из внутренних сетей.

## Коммерческие проекты вне основной работы

### DIKIDI × YCLIENTS — синхронизация систем записи

Спроектировал общую модель записей и механизм сравнения состояния двух систем. Реализовал planner/executor для создания, изменения, удаления и восстановления календарных блокировок, dry-run и проверки конфликтов. Повторный запуск учитывает уже выполненные операции.

Подключил Telegram/MAX-коммуникации, разработал web-admin на HTML5, CSS3 и Vanilla JavaScript. Контейнеризировал ботов, административный интерфейс и мониторинг; вынес состояние и Telegram-сессии в persistent volume.

Настроил Linux/Raspberry Pi, Docker Compose, systemd, Caddy/Nginx и защищённый доступ через AmneziaWG. Реализовал health-monitor: проверки VPN, Docker-сервисов, Telegram API, heartbeat и актуальности плана синхронизации, уведомления о сбоях и автоматическое восстановление части проблем.

**Стек:** Python, REST API, Telegram Bot API, Telethon, MAX API, HTML5, CSS3, Vanilla JavaScript, Docker Compose, Linux, Raspberry Pi.

### SUN MUSE — сайт студии

Разработал клиентский сайт и административный редактор контента. Добавил запись через YCLIENTS и переходы к карточке студии в 2GIS. Включил редактор в Docker-инфраструктуру проекта, организовал публикацию через reverse proxy и хранение состояния вне образа приложения.

**Стек:** HTML5, CSS3, Vanilla JavaScript, Python, Docker, reverse proxy.

### ZONT — сайт салона и визуальный редактор

Разработал сайт на React/TypeScript и клиентский редактор на Vite/Fluent UI. Реализовал 14 типов редактируемых блоков, live preview, сохранение черновиков в браузере, schema validation, undo/redo, media library и JSON import/export.

Автоматизировал получение каталога YCLIENTS через Playwright: 16 категорий и 142 услуги с ценами, длительностью и ссылками на запись. Добавил проверки количества записей и уникальности идентификаторов. Для медиаматериалов подготовил проверку файлов, manifest-каталоги и поиск визуальных дубликатов.

**Стек:** React, TypeScript, Vite, Fluent UI, Native CSS, CSS Custom Properties, Playwright, ESLint, Prettier.

## Собственный проект

### Сайт-портфолио — 3D и AI-инструменты

Разрабатываю интерактивный сайт для демонстрации опыта и проектов. Использую Next.js, React, TypeScript, CSS Modules, Global CSS, Three.js и React Three Fiber.

Создал процедурную 3D-сцену и инструменты работы с моделями. Добавил генерацию изображений и видео, анимацию изображений и реставрацию фотографий через серверные API-маршруты. Локальное удаление фона работает в браузере через ONNX Runtime Web, с ручной корректировкой маски, undo/redo и экспортом.

API-ключи остаются на сервере; предусмотрены проверки origin, типов и размеров данных, ограничения запросов и HMAC-подписанные токены для получения состояния операций. Опциональная AI-реконструкция 3D через внешнего провайдера запускается с явным согласием на передачу изображений и платную операцию.

**Статус:** в разработке. Ссылка будет добавлена после публичного развёртывания.
